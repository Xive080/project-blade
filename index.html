Rebuild the game's code in C, byte-matching the original executable.

  • Original compiler identified: CodeWarrior MIPS 2.4.1.01, -O4,p.
  • 343 functions already match the original byte for byte.
  • Automatic matching: propose C, compile, compare and retry; permuter and flag search for the hard ones.
  • RenderWare block located and excluded from matching.

RecompPISTA 2 · EN CURSOTRACK 2 · IN PROGRESS

Translate the MIPS R5900 code to C++ and link it against a runtime.

  • ~3,980 functions translated with PS2Recomp, 0 errors.
  • Boots on macOS, loads the disc’s 7 IOP modules and gets through RenderWare initialisation.
  • Reads the disc through the game’s own loader and sends its first draw packets to the GS.
  • Next hurdle: the intro video.
  • Generated code is produced locally from your disc and never distributed.

Cómo encajan

How they fit

El decomp documenta símbolos, estructuras y comportamiento, y sirve de referencia para comprobar el resultado. La recompilación busca llegar antes a algo jugable reutilizando el código original. Lo aprendido en uno alimenta al otro.

The decomp documents symbols, structures and behaviour, and is the reference results are checked against. Recompilation aims to reach something playable sooner by reusing the original code. What one learns feeds the other.
